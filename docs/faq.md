# 常见问题（FAQ）

---

## 基础问题

### 这个 Skill 是做什么的？

它定义了一套标准化的 7 阶段工作流，引导 Claude Code 从产品想法出发，逐步完成 PRD、UI 原型、技术方案、开发、测试和部署，最终交付完整产品。

### 需要会编程才能使用吗？

**不需要。** 你只需要描述你的想法，回答 Claude 提出的问题，确认每个阶段的产出物即可。代码由 Claude Code 生成。

### 支持哪些产品形态？

所有形态都支持：
- 网站 / Web 应用
- 小程序
- 移动 App
- 桌面应用
- 浏览器插件
- API 服务
- 命令行工具
- Chrome 扩展

## 安装与使用

### 如何安装？

有 3 种方式，详见 [安装指南](installation.md)：
1. 直接克隆本仓库使用
2. 作为全局 Skill 安装
3. 项目级安装

### 启动后没有进入工作流？

确保你使用了正确的触发词：

```
我有一个想法
我想做一个产品
帮我从零开发一个
我要从想法到上线
```

如果仍不生效，检查 `SKILL.md` 是否在 Claude Code 可访问的目录中。

### 可以在已有项目中使用吗？

可以。使用全局 Skill 安装方式（方式二），在已有项目目录中启动 Claude Code 即可。

## 工作流相关问题

### 每个阶段必须严格按顺序执行吗？

**是的。** 每个阶段都依赖前一阶段的产出物。如果跳过某个阶段，可能导致后续工作出现方向偏差。

### 可以修改上一阶段的内容吗？

**可以。** 直接提出修改要求即可，Claude 会更新对应文档并重新请你确认。修改确认后，再继续当前阶段。

### 如果我对技术选型不满意怎么办？

在阶段三（技术方案）中，Claude 会询问你的技术偏好。如果你有明确偏好，直接告诉 Claude。如果没有，Claude 会根据产品形态推荐最佳方案。确认后不建议频繁修改。

### 开发过程中可以添加新功能吗？

可以，但需要遵循回溯流程：
1. 更新 `docs/prd.md` 添加新功能
2. 重新确认
3. 更新 `TODO.md` 添加新任务
4. 按小步迭代模式开发

## 技术相关问题

### 生成的代码质量如何？

Claude Code 生成的代码经过以下质量保障：
- 小步迭代模式（每次只改一个任务）
- 状态覆盖（加载、空数据、异常）
- 单元测试覆盖
- 全量代码审查（阶段六）
- 需求回溯（逐条对照 PRD）

### 代码安全吗？

安全措施包括：
- 核心逻辑保护（认证、支付等不可擅自修改）
- AI 引用规则（禁止引入未声明的依赖）
- 代码审查机制

但请记住：**不要将 API 密钥、密码等敏感信息硬编码到代码中，** 应使用环境变量管理。

### 可以自定义技术栈吗？

可以。在阶段三中，Claude 会主动询问你的技术偏好。你可以指定任何框架、库或数据库。

## 其他问题

### 这个 Skill 和普通的 Claude Code 有什么区别？

普通的 Claude Code 对话是"自由模式"——你问什么，AI 答什么。本 Skill 提供了一个**结构化工作流**，确保：
1. 方向正确（先 PRD 再编码）
2. 迭代可控（一次只做一件事）
3. 质量可验证（层层测试）
4. 交付完整（文档同步）
