# 产品需求说明书 — 极简个人待办

**状态**：已确认（示例）  
**模式**：Full Flow（文档示意）

## 1. 产品概述

- **一句话定位**：浏览器内使用的极简个人待办，打开即用、数据留在本地。
- **背景**：用户厌倦功能臃肿的 GTD 工具，只想稳定勾掉今天的事。
- **不做什么**：协作、多端同步、日历、番茄钟、付费订阅。

## 2. 目标用户与画像

| 角色 | 特征 | 核心诉求 |
| ---- | ---- | -------- |
| 独立工作者 / 学生 | 单人、怕复杂 | 3 秒记下、清晰勾选 |

## 3. 核心使用场景

1. **快速记下**：打开页面 → 输入标题 → 回车出现在列表顶部  
2. **完成任务**：点击复选框 → 视觉上标记完成，可过滤隐藏  
3. **清理**：删除单条或一键清除已完成

## 4. 核心功能列表

| 优先级 | 功能 | 验收要点 |
| ------ | ---- | -------- |
| P0 | 新增待办 | 非空标题可添加 |
| P0 | 列表展示 | 未完成在前或可区分 |
| P0 | 切换完成 | 状态持久（本地） |
| P0 | 删除 | 可撤销或确认策略明确 |
| P1 | 过滤：全部/未完成/已完成 | 切换正确 |
| P1 | 本地持久化 | 刷新不丢 |
| P2 | 拖拽排序 | 可选 |

## 5. 产品形态及平台

- 静态 Web 应用（现代浏览器）
- 无账号体系

## 6. UI 风格倾向

- 极简、浅色、大点击区；参考：Things 的克制感（非复刻）

## 7. 非功能性需求

- 首屏可交互 < 2s（本地静态）
- 数据仅 localStorage，不上传
- 基本键盘可用（Tab、Enter）

## 8. 成功指标

| 指标 | 目标 |
| ---- | ---- |
| 当日任务录入成功率 | ≥ 99%（无报错） |
| 刷新后数据保留 | 100% |

## 9. 预估用户规模

个人或小范围分享；架构按单机静态站点即可。

## 10. 约束与假设

- 假设单设备；不保证多标签并发编辑冲突处理为「最后写入覆盖」并接受。
